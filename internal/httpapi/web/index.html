ledgerline · receipt extraction API

checking…

A Go microservice that turns receipt photos into structured data. Upload a receipt and watch the asynchronous pipeline work: the API accepts the job instantly, a worker extracts it in the background, and retries, a circuit breaker and idempotency keys keep it correct when things fail.

Demo mode: this public instance uses a simulated extractor so it costs nothing to run. Results are realistic but made up and do not reflect your image. The production path calls Claude vision; see the source.

3 · Break the AI provider

      
Sends documents that make the simulated provider fail like an outage. After a few consecutive
        failures the circuit breaker opens: calls stop, jobs wait in the queue without burning retries,
        and the API stays up. About 20 seconds later it lets one probe through and recovers on its own.
